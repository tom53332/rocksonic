# RockSonic Copilot Instructions

## Project Overview
RockSonic is a Go CLI tool for downloading, converting, and organizing music from Subsonic-compatible servers (like Navidrome). It can download starred songs or playlists, convert audio files to MP3, extract and resize album covers, embed covers into MP3 files, and organize files into a folder structure or flat layout.

## Key Components

### Main Entry Point
- `rocksonic.go`: Main application logic, command-line parsing, concurrent processing of songs

### Library Modules (`lib/`)
- `server.go`: Subsonic API client for authentication, fetching starred songs/playlists, downloading files
- `convert.go`: Audio conversion to MP3 using ffmpeg-go, cover extraction and resizing using ImageMagick
- `setup.go`: Directory structure creation and management
- `utils.go`: Filename sanitization for FAT32 compatibility, cover detection using ffprobe

### Data Structures
- `Song`: Represents a music track with metadata and file paths
- `Directories`: Manages various directory paths for originals, converted files, and output
- `Debrief`: Tracks what operations were performed on each song

## Dependencies
- `github.com/u2takey/ffmpeg-go`: FFmpeg bindings for audio/video processing
- `gopkg.in/gographics/imagick.v3/imagick`: ImageMagick bindings for cover processing
- Standard Go libraries: flag, fmt, os, sync, encoding/xml, net/http, regexp, strings, unicode/utf8

## Build and Run Instructions

### Building
```bash
go build -o rocksonic rocksonic.go
```

#### Windows notes
- If building on Windows, ensure `CGO_ENABLED=1` is enabled.
- Install a C toolchain and native libraries before building, e.g. Visual Studio Build Tools or MinGW/MSYS2.
- Ensure `ImageMagick` and `FFmpeg` are installed and available on `PATH`.
- Example Windows build command:
```powershell
& 'C:\Program Files\Go\bin\go.exe' build -o rocksonic.exe rocksonic.go
```

### Running
```bash
./rocksonic -url https://music.navidrome.example/rest -user username -pass password [options]
```

### Key Command-Line Flags
- `-url`: Subsonic server URL (required)
- `-user`: Username (required)
- `-pass`: Password (required)
- `-playlist`: Playlist ID to download (optional, defaults to starred songs)
- `-mp3`: Convert to MP3
- `-quality`: MP3 quality (0-9, lower is better)
- `-coversize`: Cover image size in pixels
- `-flat`: Use flat directory structure instead of artist/album hierarchy
- `-concurrency`: Number of concurrent operations (default 5)
- `-dir`: Output directory (default "./rocksonic_songs")

## Architecture Notes
- Uses goroutines with semaphore for controlled concurrency
- Downloads originals to hidden `.original/` directory
- Converts MP3s to hidden `.converted/songs/` directory
- Embeds covers and organizes final output in user-visible directory
- Sanitizes filenames for FAT32 compatibility
- Uses FFmpeg for audio conversion and cover extraction
- Uses ImageMagick for cover resizing and optimization

## Development Guidelines
- Follow Go naming conventions and idioms
- Use proper error handling throughout
- Maintain concurrency safety with sync primitives
- Keep file operations atomic where possible
- Use meaningful variable names and comments
- Test with various Subsonic servers and file formats

## Common Tasks
- Adding new audio formats: Extend conversion logic in `convert.go`
- New API endpoints: Add methods to `server.go`
- Directory structure changes: Modify `setup.go`
- Filename sanitization: Update `utils.go`
- CLI options: Add flags in `main()` function

## Troubleshooting
- Ensure FFmpeg and ImageMagick are installed on the system
- Check Subsonic server compatibility (tested with Navidrome)
- Verify network connectivity and authentication
- Use `-concurrency 1` for debugging concurrent issues
